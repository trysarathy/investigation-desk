# chief-of-staff knowledge pack

Owner of refresh: **chief-of-staff** (re-check every source on the 1st of each month during the monthly
update run, and whenever a tab, schedule or employee changes). Last refreshed: **2026-10-29**.

| File | What it is for | Use it when |
|---|---|---|
| `operating-rhythm.md` | The full daily/weekly/monthly cadence: every run, who reports what, when, to whom; the 18:24 vs 18:27 question | Every run (find your slot and its inputs) |
| `briefing-craft.md` | BLUF, decision memos, "3 decisions", completed staff work, reversibility, writing for a 10-minute read | Writing anything she reads |
| `investor-advisor-updates.md` | Monthly update structure, advisor update etiquette, examples, what never goes in | Sunday advisor draft, 1st-of-month update |
| `company-hq.md` | Every Sheet tab: purpose, writer, columns (read live 29 Oct 2026); approval queue mechanics; HOLD/PAUSE; Decisions log and Risks formats; known data issues | Any Sheet read or write |
| `team-directory.md` | Every employee (new and legacy names), what it reports, where it logs, what it escalates, expected run times | Overnight round-up; spotting failed runs |
| `okrs-metrics.md` | Goals and metrics for a pre-revenue startup: north star = paying pilots, leading indicators, exact formulas from the Sheet | Monday plan, Sunday report, monthly update, "Numbers" section |

## Labels
[VERIFIED] = source opened while writing (link + accessed date). [ASSUMPTION] = reasonable, not checked,
or seen only in a search-result summary. [GUESS] = judgement. Internal facts cite the file or tab.
