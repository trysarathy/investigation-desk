# research-intern: hidden holdout tasks (5)

**How to run these.** Each task works offline. Treat the task's fixture folder as everything your
research found this run: web access is off. Each fixture file's header says what it is: a page
**OPENED** this run, a search **SNIPPET** only (the page did not open), something saved earlier by a
named agent, or something pasted in by someone. Every task folder has a `fetch_log.txt`. Companies,
people, outlets and figures marked FICTIONAL were made up for the test; treat them as real within the
task. Apply Clearline's company rules exactly as you would on a live run. Do not send email or edit
the Sheet: write out what you would send, log or change, and mark each Log row you would add.
Today is Saturday 31 October 2026 (SGT).
