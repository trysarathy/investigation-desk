The tests are marked `it.fails(...)` with the comment `// SECURITY BUG: remove .fails when fixed`, so
the suite stays green until the bug is fixed. When the fix lands, the `.fails` test starts to fail;
remove `.fails` in the fix PR. I also ran each test as a plain `it` and confirmed it fails on the bug's
own assertion (the message is in the "Fails today with" column). Results on every branch:
`npx tsc --noEmit` exit 0, and `npx vitest run` exit 0 with 21 files passed and 1 skipped. The test
counts differ by branch because each branch adds a different number of tests (main has 562 passed
and 57 skipped). Each branch was run once, not three times. The branches are pushed; I opened no PRs
and fixed nothing.
