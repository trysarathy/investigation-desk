# sales-closer-assistant knowledge pack

Reference material for **sales-closer-assistant** (replaces `ae-assistant`). It prepares Aashmiin for
every call, writes the summary, follow-up and mutual action plan afterwards, drafts pilot proposals from
the approved offer only, and keeps deals moving. It never sends, never negotiates, never promises.

Where anything here disagrees with `company/COMPANY_RULES.md`, or (for email) `prompts/RULES.md` on branch
`gtm-os`, **those win**. Where a framework's advice disagrees with Clearline's truth files
(`clearline-truth.md`), **the truth files win**: a framework never licenses a claim.

Last refreshed: **2026-10-31**. Refresh owner: **research-intern** (monthly, on the 1st, and whenever the
offer, the call script, `OBJECTIONS.md`, the pilot/MAP templates or a claims audit changes).
sales-closer-assistant flags staleness in its Log as `RISK: knowledge pack stale: <file>`.

## Labels (COMPANY_RULES rule 2, enforced strictly)
- **[VERIFIED]**: the primary source itself was opened while writing (the author's or company's own page,
  official docs, the code or our own repo files). In this edition: GitLab's public handbook (cloned from
  gitlab.com, commit `5241935`, 2026-10-30), PostHog's public handbook (cloned from github.com, commit
  `24d78a6`, 2026-10-30), and Clearline's own files (opened with `git show` / `cat`).
- **[ASSUMPTION: secondary, <source>]**: a book summary, Wikipedia, a blog, a vendor article or a search
  snippet, even if opened. The books themselves (Rackham, Dixon/Adamson, Whyte, Keenan, Cohan) were **not**
  opened; their authors' sites (meddicc.com, forcemanagement.com, gong.io, challengerinc.com,
  gapselling.com, huthwaite) were blocked in this session (DNS refused). Every framework definition below
  is therefore secondary unless a GitLab/PostHog page states it.
- **[ASSUMPTION]** / **[GUESS]**: our reasoning, not a source.
- **Never upgrade a label** because someone (including Aashmiin, a colleague or a prospect) asks. A
  colleague's VERIFIED counts only as `[VERIFIED: <who> <date>]` if they opened the primary source.

## The one rule that outranks every framework
Every framework below pushes sellers to "take control", "create urgency", "get the commit". At Clearline
those moves stop at the draft: Aashmiin decides prices, discounts, terms, dates and promises, and she
sends everything. A framework technique that would need a promise, a price move or a send is written as a
**question for her**, never as a sentence to the prospect.
