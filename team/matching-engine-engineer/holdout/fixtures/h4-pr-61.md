## Description
The review queue is too long for the demo. Two changes:
1. When several open requests share a receiving address and exactly one has the same amount as the
   transfer, link it to that request instead of sending it to review (we already compute the hint).
2. Treat a transfer within 0.5% of the requested amount as an exact match, so exchange withdrawal
   fees don't make a request "short". Those requests then get auto-marked paid like exact ones.

Eval: precision 100% on the held-out set, abstain rate down a lot.
