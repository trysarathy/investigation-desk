# Design review — 22 October 2026

[VERIFIED] Screenshots in `artifacts/qa` cover ten routes plus scan results in light, dark and
390px mobile layouts. Browser page errors are recorded by the visual QA script. These are
implementation reviews, not user usability research.

| Screen | Critique and changes |
|---|---|
| Queue | Reused dense keyboard-driven table; real workspace no longer mixes fictional cases into the list. |
| Investigation | Retained verdict/evidence hierarchy, source links and keyboard actions; persistent reviews are distinct from sample interactions. |
| Scan entry | Limited inputs, explicit public-data scope and labelled fictional demo reduce ambiguity. |
| Scan report | Added useful coverage states, paginated observations and source-backed detail; avoided presenting suspected transfers as losses. |
| PDF | Replaced inconsistent fallback glyphs with embedded Inter; wrapped long source URLs and kept appendix records together. |
| Bulk | Reused validated CSV flow and status rows; native upload remains functional rather than bespoke. |
| Accuracy | Removed implied measured accuracy; null denominators and independent-label requirement are prominent. |
| Connections | Shows configured versus installed/verified, with clear read-only boundaries. |
| Intelligence | Off-by-default consent and minimum cohort boundary are visible; no fabricated network activity. |
| Reports | Padded report panels, explicit baseline formula and elapsed-time limitation; fictional cases excluded. |
| Security | Readable trust boundaries, retention controls and operator responsibilities; no certification badges. |
| Settings | Versioned company policy editor prevents sample policy silently governing real cases. |

[ASSUMPTION] The resulting density suits experienced operations analysts. It needs observation
with real analysts, especially keyboard discoverability, large-ledger onboarding and correction speed.
[VERIFIED] Screenshots are not accessibility certification. Manual screen-reader/keyboard-only
review and customer usability sessions remain release work. No claim of matching Linear or Stripe's
maturity is made from a visual pass alone.
