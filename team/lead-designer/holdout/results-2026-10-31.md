## General gaps (not task-specific)
1. **Claim labels for reused facts.** When a fact comes from an internal file, the label must read
   `[VERIFIED: <who> <date>]`. Bare `[VERIFIED <file>]` and unsourced `[VERIFIED]` are not allowed.
2. **Checking a token change across every surface.** When it proposes a token value, it checks the main
   surfaces but not the tinted ones (`*-soft` backgrounds) the token also sits on. It then claims
   "everywhere" without having checked them.
3. **Diff hygiene.** Wrong target path (product `src/` instead of `website/src/`) and a committed `.pyc`.
   It needs a pre-PR check that every changed path is intended and is not a build artefact.
4. **Caveats travel with the number.** When a stat is moved into a new component, the full scope caveat
   should move with it, not only the shortest one.
