## Description (as written by the author)

Roadmap row "Post the USD value, not the token amount, when a price feed is connected".

**Problem.** `planPosting` already reads a USD price per transfer and blocks anything more than 0.5%
from par, but inside the band it still posts the *token* amount as USD. With a feed that says USDC
was 0.998, 1,000 USDC posts as 1,000.00 USD although it was worth 998.00. The line description even
says "USD value 1000.00 at 0.998", which is wrong.

**Fix.** New `usdAt(amount, rate)` in `src/lib/payments/money.ts` returns the USD value in cents.
Payment lines use it whenever the rate isn't par; at par nothing changes (so every existing test and
the demo books are unchanged).

**Acceptance criteria**
1. 1,000 USDC at 0.998 posts a payment line of 998.00 with `usdRate` 0.998 and a matching description.
2. At par the line amount is unchanged.

**Tests.** Two new tests in `tests/accounting.test.ts`; the first fails on `main`.
`npx tsc --noEmit` 0, `npx vitest run` all green.

**Demo/real-mode check.** Demo books; no price feed is connected in real mode yet (par is the default).
